## Shared model selection at startup

Before substantive work, read the owner-supplied Model Selection and Escalation SOP (owner-authorized 2026-10-14). Read it once per session and reassess routing at task changes. Keep primary sessions on substantive or exceptional models as orchestrators. Select each worker model/effort by its assignment; use 2–3 concurrent subagents when useful, maximum 4 across the task tree excluding the primary, subject to lower runtime limits. Delegate bounded work rather than automatically implementing everything yourself; direct small actions are appropriate when delegation adds overhead. Preserve project code-author/reviewer pins and independent review. Persona is not a fixed model. SOP 1.1 supersedes earlier guidance to downgrade the primary for routine work.

If this runtime cannot read the path, its launcher must supply the current SOP content; a link alone is not loaded policy. Report missing context and never claim an unperformed model switch. This policy does not grant tools, permissions, provider access or new spending.
